## 本项目任务范围与依据

- 所有任务均由 [R001 分级需求](v1-platform-scope.md) 的当前业务范围、接口及 AT-01～AT-13 派生；**不得导入其他产品的旧阶段任务、旧完成率或旧需求状态**。
- EasyHostAgent 的主机执行能力与 Deploy 的应用资源清单是 EasyNetTopo 集成接口依赖，**不在本文件另建执行端或应用源的独立需求/任务汇总**；需要核实接口时读取对应仓库的现行代码和协议。
- P0 首次闭环和 P1 后续增强只是当前 R001 的交付范围与优先级，不要求新增文件/分支；同一需求复用一个工作分支和一个 PR（适用时）。
- 对于已存在源码但缺乏当前版本集成证据的条目标记 `待验证`；不因对应目录存在或其它项目测试通过就标 `已完成`。
