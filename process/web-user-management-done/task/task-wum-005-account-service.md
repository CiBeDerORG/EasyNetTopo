# WUM-005：账号管理业务与恢复

拆分后对应计划：[PLAN-WUM-004](../plan/plan-wum-004-account-contract.md)；[PLAN-WUM-006](../plan/plan-wum-006-storage-contract.md)。本任务保留原编号、状态和历史交付记录；维护入口为[需求/计划汇总](../README.md)。

需求：[Web 用户管理](../require/README.md)。计划：[PLAN-WUM](../plan/README.md)。[返回看板](README.md)。

## 目标与边界

统一实现账号查询/创建、访问状态、角色、凭据重置、会话撤销、审计和管理员初始化/恢复。user_management/ 为建议新增模块；main.rs 的最小模块声明及契约要求的恢复入口由本任务独占。

## 输入与输出契约

消费 WUM-003 的事务/存储接口与 WUM-001 的业务契约；不依赖 WUM-004 未完成的认证模块。向 WUM-006 提供明确的服务方法、错误类型与安全返回值，向 WUM-011 交付恢复步骤和升级约束。

## 执行步骤

1. 按已交付契约建立账号服务模块及安全输入/输出，在 main.rs 添加最小模块声明，使服务与测试立即参与编译。
2. 基于现成 DB 接口实现查询、创建、状态/角色变更、重置和撤销；把并发保护、版本更新与审计组织在约定事务内，存储缺口回交 WUM-003。
3. 落实契约明确的管理员初始化/恢复入口，整理恢复前提与失败处理，不扩展为新角色或跨用户资源管理。
4. 运行真实数据库服务测试，验证并发、冲突与回滚等边界，整理方法/错误和恢复步骤供 HTTP 接线与升级验收使用。

## 实施与验收

- [x] 默认创建普通本地账号；关闭自助注册不影响获授权管理员创建；用户名不可修改、不物理删除资源。
- [x] 在事务中处理状态/会话版本/角色及成功审计；并发降权或停用不能产生零个有效管理员。
- [x] 仅按确认的凭据能力重置密码；初始/恢复管理员路径不依赖用户名硬编码或首个注册用户自动提权。
- [x] 验证重复用户名、并发角色变更、失败回滚、日志脱敏、旧会话撤销需要的版本更新；保持已有资源。
- [x] 在 main.rs 注册新模块，确保代码和测试真正参与编译；记录服务测试命令及结果。
