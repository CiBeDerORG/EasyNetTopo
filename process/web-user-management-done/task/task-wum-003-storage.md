## 目标与边界

按契约扩展账号状态、会话版本、必要时间、身份绑定和审计存储；提供可供认证和业务服务独立消费的 DB 接口。新增迁移与实体注册由本任务统一负责，不修改已发布迁移。

## 输入与输出契约

输入为 WUM-001 的数据/状态/事务契约。输出为迁移后的模型、查询/修改接口、事务调用方式和测试夹具。业务事务策略由 WUM-005 负责，本项提供事务所需原子基础，避免两层各实现一套规则。

## 执行步骤

1. 对照已交付契约整理字段、默认值/空值、约束和事务接口，核对现有迁移顺序及旧数据关系；有契约缺口先回交 WUM-001。
2. 新增 migration 与实体，统一完成注册；保留历史未知信息，提供约定的列表查询和事务存储接口。
3. 在测试数据库中分别建立旧库和新库路径，执行迁移、冲突、回滚及必要原子操作验证，确认测试实际调用新增迁移。
4. 编译相关模块并整理接口使用说明、测试夹具和升级结果，交付认证与业务服务任务；不代写其业务策略。
