## 失败历史与处理

已闭合失败保留原记录，不静默删除：

- 早期集中测试缺默认 Playwright 浏览器，未进入业务断言；后明确系统Chromium。Dashboard fixture补齐 `/auth/me` 后集中33项通过，没有修改生产权限语义。
- 真实用户E2E初跑7/9，测试代理Host改写及自身CORS抢先处理影响原CSRF断言；保留Host、禁用测试代理CORS后9/9，未放宽后端校验。
- 新真实专项首次虚构用户名不合法、矩阵等待不存在字段、双语大小写及Drawer选择器不符；修正为实际页面状态后获得上述通过记录。
- 模块修复前的防重、实例切换、ACL加载失败等红灯见各模块交付；最终闭合证据见对应专项和112集中回归。不将测试基础设施失败当成产品功能失败，也不当成成功。
