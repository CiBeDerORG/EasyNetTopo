# 现有 Web 交互逻辑优化与页面美化需求

入口：[需求目录](../README.md)、[PLAN-WUI](../plan/README.md)、[任务入口](../task/README.md)。基线为 `feat/web-user-management@1e92296b`，实际实施前复核其后续提交；当前已授权实施，源码核查与真实页面取证分别记录。

## 用户任务与范围

管理员和普通用户应更容易找到已有操作、理解状态并完成原任务。本需求改善现有控制台体验，保留现有功能、接口、路由、权限与数据语义，不新增业务模块或“美化”菜单，不重做已交付用户管理。

| 既有范围 | 交互优化重点 | 页面美化重点 |
| --- | --- | --- |
| 登录、注册、本人改密 | 注册策略、表单校验、提交反馈、会话失效；保留强制改密与本地密码能力判断 | 表单对齐、提示层级、按钮状态、移动端布局 |
| 导航及工作台 Dashboard | 当前选中项、返回路径、已有入口和刷新反馈 | 导航/标题/内容分区、卡片层级、信息密度与留白 |
| 用户管理 | 现有列表/详情、搜索/筛选/分页、确认/取消、临时凭据展示和清除 | 表格可读性、详情与弹窗排版、危险操作及权限提示 |
| 设备列表、详情及实例配置入口 | 既有查看、选择、配置/保存、对象切换、失败反馈；接入命令生成与复制 | 列表/详情布局、字段分组、长文本与状态标识 |
| 网络列表与详情 | 既有创建/编辑及已支持的成员、ACL、凭据、配置操作；按真实接口表达保存/应用结果 | 现有页签、表单、列表与操作区统一，不增加业务视图 |

保留 `/auth`、`/auth/register`、`/h`、`/h/users`、`/h/password`、`/h/deviceList` 及设备/实例子路由、`/h/networks` 及网络详情路径和现有别名、深链接。页面能力以已核验基线为准，不把未接入的拓扑、EasyADB、家居或 Navloom 当作现有功能。

## 需求与边界

| 编号 | 需求 | 可观察结果与限制 |
| --- | --- | --- |
| WUI-01 | 保留现有任务与入口 | 在相同身份和数据下，原操作仍可完成；原路由、前进/返回、刷新恢复及权限限制保持可用，不通过删除功能或复杂配置项实现简洁 |
| WUI-02 | 优化交互逻辑与反馈 | 统一校验、忙碌/禁用、防重复提交、确认/取消、焦点返回、空/加载/失败/无权限状态；失败保留适当的非敏感草稿，迟到响应不覆盖当前对象，已有筛选/分页状态合理保留 |
| WUI-03 | 统一页面视觉 | 沿用 Vue、PrimeVue、已有组件和主题，统一标题字号层级、间距、颜色用途、圆角、图标、卡片、表格和弹窗；优先限于 Web 宿主，不更换框架、不升级依赖、不另建主题系统 |
| WUI-04 | 保持多语言、主题与可访问性 | 中文/英文、浅色/深色、桌面与窄屏可用；主要流程可用键盘完成，焦点清楚，输入及图标按钮有可访问名称，状态不只依靠颜色 |
| WUI-05 | 保持账号、连接与请求边界 | 保留用户权限、注册策略、临时凭据清除、强制改密和 OIDC/local 本地密码能力判断；`config-server` 连接、认证、配置下发及接入命令行为不变，不增加周期请求或后台机制 |

- 仅调整既有操作的前端编排与表达；沿用原 API、`snake_case` 字段、鉴权和业务结果，不自动重试写入、不模拟保存成功。已受理、已保存、已应用、失败和结果未知按实际响应区分。
- 接入提示可以优化排版，但 `config-server` 命令的协议、地址、端口、参数和复制内容不变；不改变客户端连接、设备认证、配置下发、协议或网络内核。
- 不新增定时器、轮询、自动刷新、心跳、WebSocket/SSE 状态订阅、后台扫描或自动重放。先记录历史页面已有请求来源，保留必要底层机制，不扩大旧计时器职责，也不借此全库清理既有机制。
- 不新增全局搜索、任务中心、主题商城或其他新业务能力，不恢复拓扑需求中已否决的 `ECO-C01～C09`。共享网络/配置组件及 GUI、配置生成器默认只读。
- 页面截图、流程证据和测试仅用隔离数据，敏感内容脱敏；网络密钥、凭据与临时密码不进入 URL、日志或设计截图。

## 验收场景

| 编号 | 场景 | 验收结果 |
| --- | --- | --- |
| WUA-01 | 同组隔离数据下对比优化前后主要流程 | 登录/注册策略、改密、用户权限、设备/实例与网络管理原流程结果一致；原路由和深链接仍可用，功能未被隐藏或删除 |
| WUA-02 | 重复提交、失败、取消和对象切换 | 一次提交只执行一次业务动作；加载/空数据/失败/无权限/结果未知区分明确，失败保留非敏感草稿；切换后不串数据，确认/取消及焦点返回清楚 |
| WUA-03 | 视觉、响应式与可访问性检查 | 覆盖中文/英文、浅色/深色、360/768/1440 像素宽度、长名称和键盘路径；关键操作可见，整页无意外横向溢出，宽表格在自身容器内滚动，状态有文本/图标说明 |
| WUA-04 | 账号与连接兼容、空闲请求观察 | OIDC-only 不开放本地改密，已有本地凭据及首次改密流程继续可用；接入命令生成/复制内容不变；config-server 及后端源码无行为改动，页面空闲无新增请求、订阅或后台机制 |

每页交付“已有任务 → 当前问题与证据 → 优化行为 → 前后截图/流程对照 → 验证结果”。静态效果图或更换配色不能替代交互验收；模拟接口只能证明相应前端行为，不能替代已承诺的真实接口验证。
