## 3. 页面与接口契约

ECO-002 维护契约基线；页面任务只消费已交付契约，接口适配任务只调用核实存在的服务。页面表单字段不能被直接当作后端 DTO，也不得为前端命名习惯修改既有 `snake_case` 契约。

### 接口能力清单

每项查询和操作记录：页面/动作、实际 API 方法与路径、所属模块、请求与响应字段、当前用户权限、状态来源/观察时间、错误语义、取消或忽略旧响应方式、可验证环境，以及对应 ECO/ECA。只有核查后才填写真实路径，不从需求建议反推接口已存在。

| 能力分类 | 设计与接入处理 |
| --- | --- |
| 已有且验证可用 | 复用现有客户端并纳入真实联调 |
| 接口存在但字段或语义不足 | 复用已确认部分，缺失字段显示未知/未支持；记录缺口及影响，不自行拼造结果 |
| 尚无接口或外部来源未核实 | 保留必要的设计说明，运行页面标明未支持并提供可理解原因；不展示会虚假成功的操作 |
| 缺少测试环境 | 标记未验证并写明前置条件；不得按已有且验证可用交付 |

在 ECO-002 固定本期实际接入清单，避免联调失败后悄悄把原本承诺的可用能力降为未支持。契约变化由协调者更新本计划与相关任务，受影响部分串行交接。

### 身份、字段与状态

- 节点使用现有宿主身份的明确映射；现有 `devices` 指 EasyTier 管理宿主，下挂手机/家居设备指业务资源。保留旧 API、路由与 ID，不能按名称、IP 或临时 peer ID 自动合并。
- 同一宿主的节点资料只保存一份视图引用；网络成员、实例、连接和访问端点分别带上下文。展示地点不以 GeoIP 覆盖人工字段。
- 公网许可、映射启用、导航可见性保持独立；用户管理权限不自动代表资源控制或公网发布权限。后端缺少必要授权能力时，该写入功能列为缺口，不能只靠隐藏按钮接入。
- 页面区分请求状态、最近接口返回的业务状态和操作结果。未知不填充为离线、零延迟或零错误；返回“已受理”不能显示“已生效”。
- 设备没有独立 IP/端口时，只展示实际存在的受控端点；不以公开整个 ADB/家居中枢代替单设备访问。

### 按需查询触发规则

| 触发 | 允许行为 | 结束条件 |
| --- | --- | --- |
| 进入页面或切换所选对象 | 查询当前页面所需数据；复用已有批量接口，避免展开一个节点读取全部站点 | 当前请求完成；切换后取消请求或忽略旧响应 |
| 用户点击刷新 | 重新查询当前对象，合并重复点击产生的在途请求 | 响应、失败或超时后停止 |
| 用户明确执行一次操作 | 发出一次操作请求；响应后按需查询受影响对象一次 | 返回实际结果；已受理/未知时提供手动刷新，不自动等待循环 |
| 页面空闲、重新联网或仅切回浏览器标签 | 不为新增资源状态发出周期或自动补偿请求 | 等待用户上述明确触发 |

日期展示使用最后一次查询/观察时间；不为了刷新“几秒前”文案引入周期状态机制。普通请求超时、按路由参数改变查询和用户手动重试不构成定时任务。接口失败保留可识别的上次数据与失败提示，不能后台重试或自动重放写入。

### 复用组件的注意事项

历史基线的 [MainPage.vue](https://github.com/CiBeDerORG/EasyTier/blob/1e92296b17fc2e85dcd4521b6012232e11abed95/easytier-web/frontend/src/components/MainPage.vue) 含导航定时刷新，部分已有状态组件也可能自行拉取数据。ECO-001/002 必须在实际实现分支核查这些行为：新增资源状态不得挂到既有定时器上，也不能复制包含轮询的组件来满足“复用”。优先复用样式、纯展示部分或已有手动模式；必要的最小前端拆分先明确所有权和受影响消费者。原有页面的既有请求与新增页面请求分开记录，保留底层组网机制，不把本期变为全库定时器清理。
